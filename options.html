⚙ Kanban Flow — Settings

JIRA Cloud connection, teams, and metric definitions.

1. JIRA Cloud connection

Format: https://<your-domain>.atlassian.net
Create one at id.atlassian.com › API tokens. Stored locally in the browser.

2. Metric settings

Variation at or below which the trend is "stable".
Leave empty for automatic detection ("Story Points" / "Story point estimate"). Fill in if your JIRA site uses an unusual field name.

Counting windows (Build mode)

Global setting: applied to all teams in Build mode. End boundaries are exclusive ("Friday end of day" = Saturday 00:00).

Tickets in Waiting or Work in progress during this window; Workflow end is excluded.

3. Teams / Projects

For each team, enter the JIRA project key. Issue types, workflow categories, and status-time chart statuses use choices retrieved for that project and selected issue types; Lead/Cycle start statuses are dropdowns populated from their own type selections.

4. Settings backup

Export your settings to a file before any extension update, then re-import it afterwards: nothing to re-enter. The file can also be shared with a colleague so they start with the same teams.

Unchecked by default: the token is a secret equivalent to a password. Without it, everything else is restored and you just need to paste the token back in. On import, a file without a token never deletes the one already saved.

5. Updates

Kanban Flow is installed manually, so the browser cannot update it on its own. This page checks the GitHub releases and walks you through the update.

Installed version: –
Downloads the package matching your browser.
  1. Export your settings first (section 4) — a quick safety net.
  2. The package has been downloaded to your usual download folder. Unzip it over your existing Kanban Flow folder, replacing the old files.
  3. Open chrome://extensions () then click Reload ↻ on Kanban Flow.
  4. Reopen the dashboard and check the version above. Your settings and API token are kept by the browser profile.
