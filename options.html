⚙ Kanban Flow — Settings

JIRA Cloud connection, teams, and metric definitions.

1. JIRA Cloud connection

Format: https://<your-domain>.atlassian.net
Create one at id.atlassian.com › API tokens. Stored locally in the browser.

2. Metric settings

First reference week. Shows the current week plus up to 3 previous completed weeks, never going back before this date. Empty = 3 previous weeks by default.
Variation below which the trend is "stable".
Leave empty for automatic detection ("Story Points" / "Story point estimate"). Fill in if your JIRA site uses an unusual field name.

Counting windows (Build mode)

Global setting: applied to all teams in Build mode. End boundaries are exclusive ("Friday end of day" = Saturday 00:00).

Tickets present on the board during this window.

3. Teams / Projects

For each team, fill in the JIRA project key and the exact statuses of your workflows. Statuses are comma-separated and must match exactly (case-insensitive) the names in JIRA.

4. Settings backup

Export your settings to a file before any extension update, then re-import it afterwards: nothing to re-enter. The file can also be shared with a colleague so they start with the same teams.

Unchecked by default: the token is a secret equivalent to a password. Without it, everything else is restored and you just need to paste the token back in. On import, a file without a token never deletes the one already saved.
